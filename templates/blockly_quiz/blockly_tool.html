Blockly là gì?

Blockly là một thư viện mã nguồn mở giúp thêm môi trường lập trình trực quan bằng cách “kéo‑thả” các khối lệnh vào ứng dụng web (hoặc di động). Thay vì gõ mã, người dùng ghép các khối lại để tạo chương trình; đằng sau, Blockly có thể sinh mã văn bản tương ứng (ví dụ JavaScript hoặc Python). Blockly ban đầu được Google phát triển và đến tháng 11/2025 thì dự án được chuyển giao cho Raspberry Pi Foundation tiếp tục duy trì. Hiện nay Blockly là nền tảng của nhiều môi trường lập trình bằng khối và được dùng rộng rãi trong giáo dục lập trình trực quan.

Mã nguồn: RaspberryPiFoundation/blockly • License: Apache‑2.0

Cài đặt (khuyến nghị cho dự án)

Dùng NPM/Yarn giúp dễ cập nhật phiên bản và tận dụng hệ sinh thái plugin.

npm install blockly

Tích hợp Blockly bằng thẻ script (nhanh)

Nếu chỉ thử nghiệm nhanh (không dùng bundler), có thể nhúng trực tiếp các file JS đã build sẵn.

  • blockly_compressed.js — core của Blockly
  • blocks_compressed.js — các block chuẩn (Logic/Loops/Math/Text…)
  • javascript_compressed.js / python_compressed.js — bộ sinh mã (tuỳ chọn)
  • msg/<ngôn_ngữ>.js — file ngôn ngữ (ví dụ msg/en.js)
  • media/ — tài nguyên icon/âm thanh (trashcan/zoom…)

Ví dụ tối giản:

<div id="blocklyDiv" style="height: 480px; width: 100%;"></div>
<xml id="toolbox" style="display:none">
  <category name="Loops">
    <block type="controls_repeat_ext"></block>
  </category>
</xml>

Khởi tạo workspace:

const workspace = Blockly.inject("blocklyDiv", {
  toolbox: document.getElementById("toolbox"),
  media: "media/",
  trashcan: true,
  zoom: { controls: true, wheel: true }
});

Trong dự án quiz này: làm sao để hiển thị đúng “câu lệnh/khối”?

Quiz render Blockly hoàn toàn trên client. Nếu câu hỏi dùng block type tuỳ biến (robotics kit, custom blocks, v.v.) thì bạn phải load đúng file JS định nghĩa các block đó (giống editor), nếu không Blockly sẽ báo thiếu block type.

Cấu hình trong .env_local (ví dụ):

BLOCKLY_QUIZ_BLOCKLY_VERSION=10.4.3
BLOCKLY_QUIZ_BLOCKLY_JS_URLS=https://unpkg.com/blockly@10.4.3/blockly_compressed.js,https://unpkg.com/blockly@10.4.3/blocks_compressed.js,https://unpkg.com/blockly@10.4.3/msg/en.js
BLOCKLY_QUIZ_BLOCKLY_MEDIA_URL=https://unpkg.com/blockly@10.4.3/media/

Gợi ý: thêm các file JS custom blocks của bạn vào cuối BLOCKLY_QUIZ_BLOCKLY_JS_URLS (sau core Blockly), sau đó restart server.
